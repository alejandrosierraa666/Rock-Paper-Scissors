# Juego de Piedra, Papel o Tijeras Multijugador

Este es un juego en tiempo real para dos jugadores, desarrollado con **Node.js** y **Socket.IO**, donde los jugadores pueden enfrentarse en partidas dinámicas a través de un navegador web.

## Descripción
Este proyecto es un juego multijugador en tiempo real donde dos jugadores se conectan a través de un servidor Node.js utilizando Socket.IO. Los jugadores eligen entre piedra, papel o tijeras, y el servidor determina el ganador de cada ronda según las reglas clásicas del juego. La interfaz está diseñada para ser simple y se ejecuta en un navegador.

## Tecnologías Utilizadas
- **Node.js**: Entorno de ejecución para el servidor.
- **Socket.IO**: Biblioteca para comunicación en tiempo real entre el servidor y los clientes.
- **JavaScript**: Lógica del juego en el cliente y servidor.
- **HTML/CSS**: Interfaz básica del juego en el navegador.
